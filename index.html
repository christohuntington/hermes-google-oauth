PERSONAL GOOGLE WORKSPACE CONNECTION

Hermes Agent

An operator-managed integration for private personal workflows.

This Google OAuth integration connects the operator's personal Google account to their self-hosted Hermes Agent installation. It supports operator-directed tasks involving Gmail, Calendar, Drive, Docs, Sheets, Contacts, and Tasks.

Access depends on the permissions the operator grants and the instructions and approval rules configured for each workflow. Google authorization does not remove those approval rules.

This is a private personal integration, not a public sign-up service. The OAuth integration described here is independently operated; this page is not an official offering from Google or Nous Research.

This static website contains only the application description and privacy policy. It does not connect to Google accounts or display their contents.
